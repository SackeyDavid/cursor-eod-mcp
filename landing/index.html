Installation

1

Install the MCP Server

Add the server to your Cursor MCP configuration:

npm install -g halo-eod-mcp

Or add to your Cursor MCP config file:

{
  "mcpServers": {
    "halo-eod-mcp": {
      "command": "node",
      "args": ["path/to/halo-eod-mcp/dist/index.js"]
    }
  }
}
2

Configure Slack Integration

In Cursor, run the configure tool:

configure

Follow the OAuth setup instructions (see below) and provide your Slack Bot Token.

3

Start Using

At the end of your day, simply type:

eod_status halo

The AI will automatically summarize your work and post it to Slack!

Slack OAuth Setup

  1. Create a Slack App

    Go to https://api.slack.com/apps and click "Create New App" → "From scratch"

  2. Name Your App

    Give it a name like "EOD Status Bot" and select your workspace

  3. Configure OAuth Scopes

    Navigate to "OAuth & Permissions" in the sidebar and add these Bot Token Scopes:

    • chat:write - Send messages
    • channels:read - Read public channels
    • groups:read - Read private channels

  4. Install to Workspace

    Scroll up and click "Install to Workspace", then authorize the app

  5. Copy Bot Token

    Copy the "Bot User OAuth Token" (starts with xoxb-)

  6. Configure in Cursor

    Run the configure tool in Cursor and paste your token

Usage Examples

Basic Usage

eod_status halo

Sends EOD update to the "halo" channel with auto-generated summary

Custom Channel

eod_status engineering-team

Send to a different channel dynamically

Manual Summary

eod_status halo summary="Completed feature X, fixed bug Y"

Provide your own summary instead of auto-generation

Configuration Tools

list_channels              # List available channels
set_default_channel general  # Set default channel
update_format_template ...    # Customize message format
preview_format              # Preview your template
