~/.cursor/mcp.json Configuration

{
  "mcpServers": {
    "@techhalo/cursor-eod-mcp": {
      "command": "npx",
      "args": ["-y", "@techhalo/cursor-eod-mcp"],
      "env": {
        "SLACK_BOT_TOKEN": "xoxb-your-bot-token",
        "SLACK_USER_TOKEN": "xoxp-your-user-token-or-empty",
        "SLACK_DEFAULT_CHANNEL": "halo"
      }
    }
  }
}

How to Get Your Slack Tokens

To use the EOD MCP, you need a Bot Token (required) and optionally a User Token.

1

Go to api.slack.com/apps and click Create New App → From scratch.

2

Name it "EOD Bot" and select your workspace.

3

In OAuth & Permissions, add these Bot Token Scopes:

chat:write channels:read groups:read
4

(Optional) Add User Token Scopes for posting as yourself:

chat:write
5

Scroll up and click Install to Workspace.

6

Copy your tokens:

  • Bot Token: Starts with xoxb-... (Required)
  • User Token: Starts with xoxp-... (Optional)

Environment Variables for MCP

SLACK_BOT_TOKEN: xoxb-your-bot-token
SLACK_USER_TOKEN: xoxp-your-user-token-or-empty
SLACK_DEFAULT_CHANNEL: halo
